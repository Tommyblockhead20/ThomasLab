Tool

Terrain Brush

In 3D Mesh mode, small brushes add/refine geometry only along the connected surface immediately around the cursor. A 1 m brush gets a true vertex at the click, with a round-ish organic footprint and no multi-meter refinement halo. Connect Cave Ends uses this Radius as the opening size, capped at 6 m for topology safety.

Core Mode

Heightfield mode. Finish the large mountain shape, then use Freeze Core to 3D Mesh. After freezing, Indent Core pushes the actual surface inward along its 3D normal, so it can form roofs and overhangs.

In 3D Mesh mode, use a small brush (about 3–6 m) and modest depth (about 0.5–2 m). Repeated clicks on the recessed back wall extend a cave naturally. To make a loop/donut cave, bring two tunnel dead ends close, choose Connect Cave Ends, click the first end, then the second. It performs a local topology stitch on the same terrain mesh; it does not create a legacy Punch Hole/collar/tunnel object.

Rock Palette

After importing a game snapshot, Bake Rocks Into Editor stores that snapshot inside your map patch so the rocks stay visible next time. This is an editor bake only; it does not yet skip procedural generation in gameplay.
